# GxDev · Portfólio (React + JavaScript)

Vite + React 18.

```bash
npm install
npm run dev      # desenvolvimento
npm run build    # gera /dist
```

Onde editar:
- `src/data.js`: links, skills, repositórios (`REPOS`) e projetos.
- `public/cv-emerson-santos.pdf`: coloque seu CV com esse nome para o botão "Baixar CV".
- `src/assets/`: logos, foto e imagens dos projetos.
